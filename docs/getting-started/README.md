# Getting Started with llm-memory

Welcome! This guide will help you get started with llm-memory quickly.

## What is llm-memory?

llm-memory is a local developer AI agent with persistent memory and GitHub Copilot integration. It stores architectural policies and knowledge in a PostgreSQL database with vector search capabilities.

## Choose Your Setup

### 🚀 Quick Start (5 minutes)
**Local Development on Windows/Mac/Linux**
- Best for: Testing, development, learning
- Requirements: Docker Desktop
- [→ Local Setup Guide](../deployment/local/README.md)

### 🏠 Production Setup
**Deploy to Synology NAS**
- Best for: Always-on service, shared team access
- Requirements: Synology NAS with DSM 7.2+
- [→ NAS Deployment Guide](../deployment/nas/README.md)

## What Can You Do?

1. **Store Architectural Knowledge**: Keep coding standards, patterns, and decisions in persistent memory
2. **Query from Copilot**: Get context-aware suggestions based on your team's policies
3. **Semantic Search**: Find relevant policies using natural language queries
4. **Web UI**: Manage policies and view history through a modern interface
